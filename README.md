# AirQualityProject

Исследование динамики загрязнения воздуха и погоды в Алматы.
Даты наблюдений и исходные периоды сохранены: загрязнение — октябрь 2026,
погодный архив — 01.11.2025–31.10.2026. Время сбора AQICN хранится с часовым поясом.

## Установка и запуск

Python 3.10+; для сетевых сборщиков Selenium нужен установленный Firefox.
В терминале из папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py check
.\.venv\Scripts\python.exe main.py analyze
```

Без команды `main.py` выполняет локальный анализ. Он не обращается к сайтам
и не открывает браузер. Создаёт календарную таблицу `data/daily_analysis.csv`,
отчёты в `reports/` и графики в `plots/`. Повторный запуск обновляет эти результаты.
`plot_graphs.py` и `visualization.py` оставлены как совместимые точки запуска того же анализа.

## Сбор данных

Запускается отдельно, требует интернета; для Selenium открывается Firefox:

```powershell
python main.py collect --source open-meteo
python main.py collect --source aqicn
python main.py collect --source cerns
python main.py collect --source pollution-alert
python main.py collect --source weather-month
python main.py collect --source weather-year
```

Open-Meteo собирает предыдущие сутки и объединяет их с историей по времени,
городу и источнику. AQICN добавляет снимки индексов с временем сбора.
CERNS сохраняет и объединяет записи октября 2026. Остальные архивные сборщики
обновляют соответствующие файлы за заданный период; годовой сборщик может
сохранить неполный результат при ошибках сайтов — проверяйте его итоговый вывод.
История CERNS на странице ограничена `range=20d`: повторный запуск не гарантирует
восстановления пропущенного начала октября. Существующий CSV не заменяет полный архив.
Даты в архивных сборщиках оставлены явно в коде.

## Данные и единицы

| Файл в data/ | Содержание |
| --- | --- |
| open_meteo_hourly.csv | Почасовые PM2.5 и PM10, мкг/м³; поле time, источник Open-Meteo |
| aqicn_observations.csv | Индексы AQI по загрязнителям; collected_at — время сбора, не подтверждённое время измерения |
| almaty_october_2026.csv | CERNS: суточные концентрации, AQI, часы наблюдений и число станций |
| pollution_alert_october_2026.csv | Модельные данные CAMS; хранятся отдельно от наблюдений CERNS |
| almaty_weather_october_2026.csv | Погода за октябрь, °C и мм осадков |
| almaty_weather_year.csv | Годовой погодный архив, источник «Погода и климат» |
| daily_analysis.csv | Производная таблица: все 31 сутки октября, источники и флаг air_day_complete |

Смешанный `air_quality_almaty.csv` разделён без потери строк: 24 почасовые записи
и 2 записи AQI. Оригинал находится в `data/archive/` и не участвует в анализе.
Скриншоты и сохранённый HTML перенесены в `debug/`. `airdata_parser.py` —
инструмент исследования страницы, а не готовый сборщик; его снимок также идёт в `debug/`.

## Результаты и ограничения

- `reports/data_quality.md`: пропуски дат и значений, дубликаты, некорректные даты,
  отрицательные показатели, порядок температур и полнота суток.
- `reports/summary.md`: сводка, максимум PM2.5 и корреляции с размером выборки.
- `reports/statistics.csv`: описательная статистика полных суток.
- `reports/correlations.csv`: парные корреляции Пирсона и число наблюдений.
- `plots/`: динамика PM, AQI, температуры, связи PM2.5 с погодой и годовая сводка.

Основной анализ объединяет CERNS и годовой погодный архив по дате и городу.
Неполные сутки исключены из статистики; отсутствующие значения не заполняются.
На графиках загрязнения пропуски разрывают линии. Контрольные проверки описывают
состояние данных, но не исправляют автоматически подозрительные значения.
Сейчас доступны лишь 15 полных суток загрязнения: выводы предварительные,
корреляция не доказывает причинность. Сетевые сборщики после реорганизации
не проверялись на живых сайтах; изменения разметки могут потребовать правок.

Для прогноза следующий шаг — расширить историю загрязнения, добавить ветер
и влажность, затем сравнить модель с простым прогнозом предыдущего дня.
Обучающую и проверочную выборки следует разделять по времени; интерполяцию,
масштабирование и признаки рассчитывать без доступа к будущим наблюдениям.
